# Denario vs. Paradigm — Architecture Analysis & Learnings

**Date:** 2026-06-03
**Scope:** A thorough, code-level analysis of **Denario** (`/Users/mcantiello/astro/Denario`, v1.0.1, GPL-3, by Villanueva-Domingo / Villaescusa-Navarro / Bolliet — AstroPilot-AI / Flatiron / Cambridge) and a head-to-head comparison with **Paradigm**, to identify design choices worth adopting. ## 1. What Denario Is

Denario is a **modular multi-agent scientific research assistant** built as a thin Python orchestration layer over two frameworks — **LangGraph** (fast path) and **AG2/AutoGen via `cmbagent`** (deep path) — plus external services (**FutureHouse PaperQA**, **Semantic Scholar**, **Perplexity**). It is ~5,100 LOC (vs Paradigm's ~25k). Public API is a **stepwise, human-driven pipeline**:

```python
den = Denario(project_dir="...")
den.set_data_description(prompt)   # human supplies data + tools description
den.get_idea()                     # idea_maker ⇄ idea_hater
den.check_idea()                   # novelty vs literature (FutureHouse or Semantic Scholar)
den.get_method()                   # methodology
den.get_results()                  # cmbagent runs code → results + plots
den.get_paper(journal=Journal.APS) # journal-ready LaTeX + grounded citations
den.referee()                      # multimodal review report
# or: den.research_pilot(prompt)   # run all of the above end-to-end
```

**Provenance / validation (a real differentiator):** Denario v1.0 (Nov 2025), arXiv:2510.26887; a paper *fully generated by Denario* was accepted at the **Open Conference of AI Agents for Science 2025** (AI as primary authors); featured in the **LSST DESC AI Roadmap** (Jan 2026); its backend **cmbagent won 1st place at NeurIPS 2025 Fair Universe**. There is a deployed GUI (DenarioApp) and a HuggingFace demo. Paradigm currently has none of this external validation.

## 2. Architecture Overview

### 2.1 The defining choice: two backends, speed-vs-quality toggle
Most generative stages expose `mode="fast"` (LangGraph, one-shot LLM nodes, cheaper, "less reliable") vs `mode="cmbagent"` (multi-agent planning/control, slower, "more reliable"). The *user* picks per stage. Denario's own docstring: *"cmbagent, for detailed planning and control involving numerous agents… langgraph, for faster idea and method generation, and for the paper writing."* Paradigm has a single execution path per phase.

### 2.2 State = editable Markdown files on disk
The entire shared state is a tiny Pydantic model:
```python
class Research(BaseModel):
    data_description: str; idea: str; methodology: str
    results: str; plot_paths: list[str]; keywords: dict | list
```
Each field is persisted as a Markdown file in `project_dir/input_files/` (`idea.md`, `methods.md`, `results.md`, `literature.md`, `Plots/`). On init, `set_all()` reloads any present files. **Consequence:** a human can open any artifact, edit it, or inject their own via `set_idea(path.md)` / `set_method(...)` / `set_results(...)` between steps. State is radically inspectable and overridable — the human-in-the-loop is structural, not bolted on. Paradigm's state lives in SQLite + git threads + Pydantic checkpoints — more powerful, but less casually editable mid-run.

### 2.3 The stack
- **LangGraph** (`langgraph_agents/`, `paper_agents/`): `StateGraph` with `TypedDict` state, conditional routers, `MemorySaver` (in-memory) checkpointer, fixed `thread_id="1"`, `recursion_limit=100`. One graph serves idea/literature/methods/referee via a `task` field + `task_router`.
- **cmbagent** (`idea.py`, `method.py`, `experiment.py`): every deep stage funnels into a single API — `cmbagent.planning_and_control_context_carryover(...)` — passing per-role models, instructions, `work_dir`, `api_keys`, and control budgets. cmbagent owns the agent dialogue, the code-execution environment, plot capture, planning/replanning, and retries.
- **External services:** FutureHouse PaperQA (`owl` job) for novelty; Semantic Scholar API for literature; Perplexity (`sonar-reasoning-pro`, domain-filtered to `arxiv.org`) for citation grounding.
- **Models:** OpenAI (gpt-4o, gpt-4.1, o3-mini, gpt-5), Gemini (2.0/2.5-flash, 2.5-pro), Anthropic (3.7-sonnet, opus-4/4.1) via a `models` registry.

### 2.4 Topology sketches
**Research graph (fast path), one graph, four entry points via `task`:**
```
START → preprocess → task_router ┬─ idea_generation → maker ⇄ hater  (loop ×N) → END
                                 ├─ methods_generation → methods → END
                                 ├─ literature → novelty ⇄ semantic_scholar → literature_summary → END
                                 └─ referee → referee(PDF→images→VLM) → END
```
**Paper graph (linear pipeline, per-section nodes, caching + versioning):**
```
preprocess → keywords → abstract → introduction → methods → results → conclusions
   → plots(caption+insert, batched) → refine_results → [citation_router] → citations → END
   (each section: generate ≤3–5× → extract block → optional self-reflection → LaTeX_checker → XeLaTeX compile → fix_latex on error)
   (paper versions saved v1 preliminary → v2 plots/refined → v3 citations → v4 final)
```

## 3. Stage-by-Stage Deep Dive

### 3.1 Idea — `idea_maker` ⇄ `idea_hater` (propose-critique)
- **Fast:** a maker node emits `\begin{IDEA}…\end{IDEA}`; a hater node ("be a *harsh* critic"; judges feasibility/impact) emits `\begin{CRITIC}…`; loops back. **Fixed count** (`total_iterations`, default 4); **no quality threshold, no ranking, no tournament.**
- **cmbagent (deep):** a planner scripts the loop explicitly — *"idea_maker generates 5 ideas → idea_hater critiques → idea_maker selects & improves 2 → idea_hater critiques → idea_maker picks the best → report as a title + 5-sentence description."* The hater/reviewer roles use a **reasoning model (o3-mini)**.
- **vs Paradigm:** Paradigm's `knowledge/hypothesis_tournament.py` + `debate.py` + `skeptic` is **strictly more sophisticated** here (Elo-style ranking, multi-agent debate, world models). Denario's idea stage is a fixed propose-critique with no selection signal. *Paradigm is ahead.*

### 3.2 Literature / Novelty — external-agent delegation
- Two modes: **FutureHouse PaperQA** (`owl` job: "Has anyone worked on this idea? Answer yes/no + related work") or a **LangGraph Semantic Scholar agent** that loops `novelty → semantic_scholar → novelty`, where an LLM returns JSON `{Reason, Decision∈{novel|not novel|query}, Query}`, **first round forced to `query`**, capped at `max_iterations=7`, with robust API retries (up to 200 attempts). Produces a `\begin{SUMMARY}` narrative.
- **vs Paradigm:** Paradigm builds its *own* multi-provider literature service (arXiv/bioRxiv/PubMed/ADS/S2/Perplexity + `novelty.py` + `citation_chains.py`). Denario instead **consumes FutureHouse PaperQA** — a mature, RL-trained literature agent that beats humans at lit search. *Lesson: consuming a best-in-class external novelty agent is an option Paradigm dismisses by building its own.*

### 3.3 Method — single researcher, workflow-only
cmbagent planner + researcher produce a ~500-word Markdown methodology; prompts **explicitly ban "future directions / extensions / limitations"** ("write as if a senior researcher explaining to a research assistant"). Clean, scoped output.

### 3.4 Experiment / Results — delegated to cmbagent, with step-restart
- `cmbagent.planning_and_control_context_carryover(...)` with an **engineer** (writes/executes code, makes plots) and a **researcher** (interprets → ~2000-word Results). Control budgets: `max_n_steps=6` (plan depth), `max_n_attempts=10` (retries per failed step), `max_rounds_control=500`, and **`restart_at_step`** — resume a failed multi-step experiment *from a given step without replanning the whole thing*. `hardware_constraints` (e.g. "no GPU") is passed into the engineer so generated code adapts.
- **The "console-as-data-bus" contract (notable):** the engineer is told to **print ALL quantitative results to stdout** because *"the researcher agent cannot load files — only reads console output."* This forces complete, explicit results reporting and prevents the interpreter from inventing or silently dropping numbers.
- Plots auto-captured via cmbagent's `final_context['displayed_images']`.
- **vs Paradigm:** Paradigm runs its **own Docker sandbox** (`--network=none`, CPU/mem limits, pattern scan) with a retry loop + circuit breaker + per-round checkpoint *context*. But Paradigm has **no `restart_at_step`** (resume a failed N-step plan from step k) and no explicit "console-as-data-bus" contract. cmbagent's execution environment is, from Denario's side, somewhat opaque (less safety control than Paradigm's sandbox). *Paradigm wins on safety/control; Denario wins on restart granularity and the reporting contract.*

### 3.5 Paper writing — journal-ready LaTeX with a compile-repair loop (Denario's standout)
- **Per-section nodes** (abstract → intro → methods → results → conclusions), each prompt fed the title/abstract + prior sections for coherence; abstract & intro get **self-reflection rounds**.
- **Every section is compile-tested:** `LaTeX_checker()` → **XeLaTeX compile** → on error, parse the `.log`, send the error + section text to an LLM (`fix_latex_bug_prompt`), recompile (≤3 attempts). This is an **LLM-driven LaTeX error-repair loop**.
- **Real journal output:** `Journal` enum (NONE/AAS/APS/ICML/JHEP/NeurIPS/PASJ) selects a `LatexPresets` (document class `aastex631`/`revtex4-2`/etc., bibliography `.bst`, template `.cls`/`.sty` files, two-column layouts). Output is submission-shaped `.tex` + `.bib`.
- **Citation grounding (anti-hallucination):** sections are written **without citations**; afterward, paragraphs of Intro+Methods are sent to **Perplexity `sonar-reasoning-pro` filtered to `arxiv.org`**, which returns `[n]` markers; each is resolved via `arxiv.org/bibtex/<id>` → real BibTeX; `[1][2]` → `\citep{key1,key2}` (deduped, year-sorted); **failed lookups are dropped, never invented.**
- **Per-section caching + paper versioning (v1→v4)** make the writing phase resumable.
- **Plots:** images → base64, captioned in batches (≤7/call, ≤25 total), inserted into Results, then a `refine_results` node rewrites Results to integrate `\ref{fig:…}` references; `check_images_in_text()` verifies every figure is referenced.
- **vs Paradigm:** Paradigm outputs **Markdown** (with Unicode→LaTeX math conversion in `journal/paper.py`), no journal templates, no compile gate. *This is Denario's clearest, most adoptable advantage.*

### 3.6 Referee — multimodal (renders the PDF, looks at the figures)
The referee **renders the paper PDF to PNGs (PyMuPDF, 200 DPI), base64-encodes them, and feeds images + text to a multimodal LLM** which finds flaws, checks correctness, verifies evidence supports conclusions, judges publication-worthiness, and **scores 0–9** (`\begin{REVIEW}`). It is a **single feedback report** — there is **no accept/revise/reject decision, no revision loop, no publish gate, no editor.**
- **vs Paradigm:** Paradigm's `journal/` is a full pipeline — editor desk-review → 2 independent reviewers → synthesized **decision (accept/revise/reject)** → revision rounds → publish or graveyard. *Paradigm is far ahead structurally.* But Paradigm's reviewers are **text-only**; Denario's reviewer **visually inspects figures** (the same VLM-check trick AI Scientist v2 used to kill figure defects). *That one trick is worth stealing.*

## 4. Head-to-Head Comparison

| Dimension | **Denario** | **Paradigm** |
|---|---|---|
| **Philosophy** | Thin layer over frameworks; stand on external shoulders | Plain-Python, no frameworks, full control (explicit anti-LangChain/AutoGen rule) |
| **LOC** | ~5,100 | ~25,000 |
| **Orchestration** | LangGraph StateGraph + cmbagent AG2 | Deterministic plain-Python phase machine |
| **Autonomy** | **Human-driven stepwise** (call each method, edit artifacts between) | **Autonomous full-cycle loop** + optional intervention hook |
| **Execution backend** | Delegated to **cmbagent** (opaque env) | **Own Docker sandbox**, `--network=none`, limits, pattern scan |
| **Experiment restart** | **`restart_at_step`** (resume failed plan from step k) | Per-round checkpoint *context* only; no step-restart |
| **Idea selection** | Fixed-count idea_maker/hater; no ranking | **Hypothesis tournament + debate + world model** |
| **Literature** | FutureHouse PaperQA **or** Semantic Scholar agent | Own multi-provider service (arXiv/bioRxiv/PubMed/ADS/S2/Perplexity) + novelty + citation chains |
| **Peer review** | Single multimodal referee report (score 0–9), **no decision** | **Editor + 2 reviewers + accept/revise/reject + revision rounds + graveyard** |
| **Reviewer modality** | **Multimodal (sees figures)** | Text-only |
| **Output format** | **Journal-ready LaTeX** (7 presets) + grounded BibTeX | Markdown (+ Unicode→LaTeX math) |
| **Citation grounding** | Perplexity→arxiv-only→real BibTeX, failed refs dropped | `citation_handler.py` + perplexity.py (own pipeline) |
| **Cross-cycle memory** | **None** (stateless across runs) | **Episodic agent memory + reflection (ChromaDB)** |
| **Reputation/incentives** | None | **Reputation-weighted agents** |
| **Per-role model heterogeneity** | Yes (reasoning models for critics) | **Yes** (opus-4-6 research roles, gemini-3-pro writer/editor, Qwen/DeepSeek cheap roles) |
| **Token budgets** | cmbagent control-loop limits | **Explicit per-thread (1M) / per-agent (100–300k) budgets** |
| **Research artifact** | Flat Markdown files in project dir | **Git-based research threads** (versioned, forkable) |
| **Public validation** | **Published papers, LSST DESC, NeurIPS award, GUI** | None yet |

**Net read:** Paradigm is the more ambitious, more complete *autonomous* system (memory, reputation, tournaments, real journal, git threads, sandboxed execution). Denario is a leaner, **human-in-the-loop assistant** that wins decisively on three things Paradigm should care about: **(1) publication-grade LaTeX output, (2) figure-aware review, and (3) real-world validation/distribution.** It also has two clean robustness patterns (step-restart, compile-repair) and one philosophical bet (delegate to mature external components) worth weighing.

## 5. The Philosophy Divergence (and why it's mostly *not* a blocker)

Denario embraces frameworks (LangGraph, AG2/cmbagent) and external agents (PaperQA); Paradigm's `CLAUDE.md` explicitly forbids LangChain/CrewAI/AutoGen and "don't add a web server/API until the CLI works." These are genuinely opposed bets:
- **Denario's bet:** maximize leverage — a 5k-LOC layer rides a NeurIPS-winning execution backend and a human-beating literature agent, and ships real papers fast.
- **Paradigm's bet:** maximize control — a deterministic, debuggable, fully-owned stack that can do things frameworks can't (reputation, cross-cycle memory, git threads, strict token economics).

**Key insight:** almost everything worth stealing from Denario is **leaf-level technique, not framework dependency.** LaTeX/journal output, the compile-repair loop, the multimodal referee, citation grounding, step-restart, and the console-as-data-bus contract can all be implemented in plain Python *without* adopting LangGraph or AG2. So Paradigm can absorb Denario's output-quality wins while keeping its architecture. The only genuinely *strategic* (decision-requiring) lessons are: (a) whether to *optionally* delegate execution to cmbagent, and (b) whether to *consume* an external novelty agent (PaperQA) — both are "build vs. buy" calls, not forced.

## 6. What Paradigm Should Adopt from Denario

Ranked; each tagged **[leaf]** (philosophy-compatible, low risk) or **[strategic]** (needs an explicit decision), with the target module.

### High value
1. **[leaf] Journal-ready LaTeX output with a compile-repair loop.** Add a LaTeX rendering path alongside Markdown: per-section `.tex`, journal presets (start with NeurIPS/AAS/APS), `bibtexlatex`/`xelatex` compile, and an **LLM error-repair loop** (parse `.log` → fix → recompile, bounded retries). This is the single biggest credibility upgrade and a direct enabler of "submit a real paper." *Target:* new `journal/latex.py` + presets; `orchestrator/writing.py`. *Cross-ref:* matches the external-synthesis push to produce defensible, submission-shaped output.
2. **[leaf] Make reviewers (and a writing-phase check) multimodal.** Render the draft's figures to images and have the reviewer/skeptic *see* them — caption↔figure alignment, missing labels, duplicated figures, misleading axes. Cheap, high-yield, kills a whole class of embarrassing defects. *Target:* `journal/review.py`, `orchestrator/writing.py`. *Cross-ref:* this **is** direction **D8** (VLM figure check) from the external synthesis — Denario confirms it in production.
3. **[leaf] `restart_at_step` for the experiment phase.** Let a failed multi-step experiment resume from step *k* using saved per-step artifacts, instead of restarting the phase. Directly attacks the 38% `writing_failed` and token waste. *Target:* `orchestrator/experimentation.py` + `storage/checkpoints`. *Cross-ref:* the granular sibling of direction **D2** (tree-search stage checkpoints).
4. **[leaf] Tighten citation grounding to "resolve-or-drop."** Adopt Denario's discipline: draft sections citation-free, then ground citations against a real source (arXiv/S2/Perplexity), convert to real BibTeX keys, and **drop any reference that fails to resolve — never emit an unresolved/invented cite.** *Target:* `orchestrator/citation_handler.py`, `literature/citations.py`. *Cross-ref:* the concrete mechanism behind **D1**'s anti-fabrication lint.
5. **[leaf] "Console-as-data-bus" contract between experimentalist and analyst.** Require the experimentalist's code to print *all* quantitative results to stdout, and have the analyst interpret *only* captured stdout/artifacts — not free recall. Forces complete, traceable reporting and curbs invented numbers. *Target:* experimentalist/analyst prompts + `experimentation.py` capture. *Cross-ref:* supports **D1** (re-execution/traceability).

### Medium value
6. **[leaf] Controlled-vocabulary keyword extraction.** Denario matches keywords against UNESCO/AAS taxonomies (no hallucinated keywords). Paradigm could ground keywords/subject tags to a controlled list per domain. *Target:* `journal/`, `domains/`.
7. **[leaf] Per-section caching + paper versioning (v1→v4).** Cache each generated section to disk and snapshot paper versions so the writing phase is resumable and diffable. Paradigm's git threads already give versioning — formalize writing-phase checkpoints similarly. *Target:* `orchestrator/writing.py`.
8. **[strategic] Speed-vs-quality mode toggle per phase.** Denario's `mode="fast"|"cmbagent"` lets a user trade cost for reliability. Paradigm could expose a per-phase "effort" level (cheap single-pass vs full multi-agent tournament/debate), tied to its token budgets. *Target:* `config.py`, `orchestrator/engine.py`. *Cross-ref:* dovetails with the "tier compute by Elo/assurance level" idea from the external synthesis.
9. **[strategic] Verify reasoning-model assignment for critic/review roles.** Paradigm already does per-role models, but Denario deliberately puts its strongest *reasoning* model on the critic/reviewer/plan-reviewer roles. Audit `configs/default.yaml`: ensure skeptic, reviewer, and editor get the best reasoning model, not the writer-tier model. *Target:* `configs/default.yaml`. (Low effort, possibly already true — verify.)

### Strategic build-vs-buy (decision required, not default)
10. **[strategic] Optionally consume an external novelty/literature agent (FutureHouse PaperQA).** PaperQA is RL-trained and beats humans at lit search. Paradigm could offer it as an *additional* novelty provider behind its existing abstraction (it already wraps it conceptually via `literature/providers`). Keeps the in-house service as default; adds a stronger option. *Cross-ref:* aligns with **D10** (consume external literature MCP/agents).
11. **[strategic] Optionally delegate heavy execution to cmbagent.** cmbagent is a mature, award-winning execution backend. Adopting it conflicts with the "full control / own sandbox / no AutoGen" principle and would weaken Paradigm's safety story (`--network=none`). **Recommendation: do NOT adopt** — instead, borrow cmbagent's *ideas* (step-restart, planner/engineer/researcher separation, hardware-constraint awareness) into Paradigm's own sandbox. Listed for completeness.

## 7. What Paradigm Already Does Better (keep / lean into)

For confidence and positioning — these are real moats Denario lacks:
- **Autonomous full-cycle loop** with a deterministic phase machine (Denario is manual stepwise).
- **Idea selection science:** hypothesis tournaments + multi-agent debate + world models + conflict detection + evidence graph (Denario: fixed-count propose-critique, no ranking).
- **A real internal journal:** editor + two independent reviewers + accept/revise/reject **decision** + revision rounds + graveyard (Denario: one referee report, no decision/revision/publish gate).
- **Cross-cycle learning:** episodic agent memory + reflection (Denario: stateless across runs).
- **Reputation/incentive system** (Denario: none).
- **Git-based research threads** — versioned, forkable, citable research-as-software (Denario: flat Markdown files).
- **Own sandbox with explicit safety** (`--network=none`, limits, pattern scan) + **strict token economics** (per-thread/per-agent budgets) (Denario: opaque cmbagent env, control-loop limits only).
- **Domain-agnostic multi-provider routing** including open models (Together/Qwen/DeepSeek) for cost (Denario: OpenAI/Gemini/Anthropic).

**The gap that matters most is not capability — it's output polish + validation.** Denario ships *journal-ready papers* and has *published* them; Paradigm has richer machinery but Markdown output and no public proof points. Closing items 1–5 above + producing one real, validated paper would flip that.

## 8. Convergence With the External-Source Synthesis

Reassuringly, Denario independently confirms several directions from the Prompt-68 reading synthesis — when an external-paper idea *and* a shipping competitor both point the same way, it's a high-confidence bet:

| External-synthesis direction | Denario evidence | Combined takeaway |
|---|---|---|
| **D8** VLM figure/format check | Denario's referee renders the PDF and inspects figures | **High-confidence:** make review multimodal. |
| **D2** tree-search + stage checkpoints | Denario's `restart_at_step` + `max_n_steps`/`max_n_attempts` | Stage-level resumability is proven; build it. |
| **D1** verification kernel / anti-fabrication | Denario's "resolve-or-drop" citations + console-as-data-bus | Ground every claim/cite to an artifact or drop it. |
| **D10** consume external literature agents | Denario consumes FutureHouse PaperQA | A real option, not just theory. |
| **Reframe success from throughput → insight + human gates** (Nature/Imas) | Denario is human-driven stepwise by design | Both argue: keep humans editing artifacts between stages. |
| **Tier compute by effort/assurance** | Denario's fast vs cmbagent mode toggle | Expose a per-phase effort dial. |
| Journal-ready output as the credibility play | Denario's published papers via LaTeX presets | Markdown→LaTeX is the missing credibility layer. |

**Divergence worth noting:** the external frontier (AI Scientist v2, Co-Scientist, taste paper, SkillOpt) pushes toward *more autonomy and self-improvement*; Denario deliberately stays *human-in-the-loop and stateless*. Paradigm sits between them — it should keep its autonomy/memory/reputation moat (where it beats Denario) while adopting Denario's output-quality and validation discipline, and layer in the external frontier's verification + taste + skill-evolution mechanisms.

## 9. One-Paragraph Summary

Denario is a lean (~5k LOC), framework-based (LangGraph + AG2/cmbagent), **human-in-the-loop** research assistant that delegates execution to a mature backend and literature to FutureHouse PaperQA, and whose decisive strengths are **journal-ready LaTeX output**, a **figure-aware multimodal referee**, **step-level experiment restart**, **resolve-or-drop citation grounding**, and **real published-paper validation**. Paradigm is a larger (~25k LOC), framework-free, **autonomous** platform that is architecturally *ahead* on idea selection (tournaments/debate), peer review (real editor+reviewers+decision pipeline), cross-cycle memory, reputation, git-based research threads, sandbox safety, and token economics — but *behind* on output polish and external validation. The optimal move is asymmetric absorption: adopt Denario's five leaf-level output/robustness techniques (LaTeX+compile-repair, multimodal review, step-restart, citation resolve-or-drop, console-as-data-bus) without adopting its frameworks, keep Paradigm's autonomy/memory/reputation moat, and fold both into the verification-kernel / taste / skill-evolution roadmap from the external synthesis.
